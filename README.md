# programon
簡易互動式回合制遊戲
實際演示影片：https://drive.google.com/file/d/1dTr9_58pQbSzDn2GTTu-gFFW15JpiOCA/view?usp=drive_link
遊戲檔案：https://drive.google.com/file/d/1zljiod2LMUUIVvYF7Y4J6bJlHIwWKw2X/view?usp=drive_link
w(上) a(左) s(下) d(右)移動、F互動鍵
當遭遇敵人按下F時，晃動模組會正轉1秒，接著會進入戰鬥
提升攻擊力時，風扇會啟動
降低攻擊力時，冷熱模組會啟動
造成傷害時，震動模組會啟動
